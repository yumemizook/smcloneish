# WebSM Rhythm Game

A web-based rhythm game inspired by StepMania/ITG, built with vanilla HTML, CSS, and JavaScript.

## Features

- **Browser-based Gameplay**: Run the game directly in your web browser.
- **File Support**: Supports `.sm` and `.ssc` simfile formats.
- **Local Import**: Drag and drop or select local folders/zip files to load your song library.
- **Customizable**:
  - Speed, Scroll Direction (Up/Down), Perspective Effects.
  - Keybindings.
- **Detailed Stats**: offset graphs, judgment counts, and NPS graphs.

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a modern web browser (Edge, Chrome, Firefox).
3. Import your song packs using the "Import Folder" or "Import Zip" buttons.

## Controls

Defatult keybindings:
- **Left**: `D`
- **Down**: `F`
- **Up**: `J`
- **Right**: `K`
- **Confirm/Start**: `Enter` (or click UI buttons)
- **Back/Pause**: `Esc`
